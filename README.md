# 🪽 전설의 날개 대모험

마우스로 조작하는 2D 비행 슈팅/러너 게임입니다. 순수 HTML/CSS/JS(+Canvas)로 제작되어 별도 설치나 서버 없이 `index.html`을 브라우저에서 열기만 하면 바로 실행됩니다.

## 실행 방법

`index.html` 파일을 더블클릭하거나 크롬/엣지 등 브라우저로 열면 됩니다.

## 조작

- **마우스 이동**: 비행 중 캐릭터가 마우스를 부드럽게 따라 이동
- **Space Bar**: 전투(몬스터 조우) 중 칼 공격
- **숫자키 1~2~3~4**: 인벤토리 아이템(복숭아/보석/원숭이/의자) 사용 (클릭도 가능)
  - 3번(원숭이) 사용 시 비행이 일시정지되고, 임시로 변신할 날개를 고르면 다시 진행됩니다.

## 씬 구성

- **방(Room)**: 보석함 / 트로피 전시대 / 냉장고 / 날개 걸이, 상점으로 나가기, 비행 출발
- **상점(Shop)**: 돈 10 → 보석 1 교환, 우편함(편지 확인)
- **비행 스테이지(Flight)**: 60초 턴 동안 코인/돈 획득, 장애물 회피, 몬스터 조우 시 강제 전투(Cage 연출)

## 우편 시스템

비행 턴을 마칠 때마다 상점 우편함에 무작위 편지가 1통 도착합니다 (최대 1통 대기, 안 읽으면 쌓이지 않고 유지). 우편함 아이콘의 빨간 점으로 새 편지 여부를 표시합니다.

| 편지 | 효과/이벤트 |
|---|---|
| 몬스터가 보석을 먹었다 | 보석 -1 (즉시) |
| 보석함에 숨으라는 경고 | 다음에 방으로 돌아가면 5초 안에 보석함을 클릭해 숨어야 함. 실패 시 목숨 -0.5 |
| 몬스터가 보석 광산에 갔다 | 다음 비행에서 몬스터를 처치하면 보석 +1 추가 (1회성) |
| 무더위/전기세 인상 | 돈 -1 (즉시) |
| 주문한 과자 도착 | 돈 -1, 목숨 +0.5 (즉시) |

## 장애물 테마 시스템

비행 중 등장하는 장애물은 6개 테마(우주/바다/디저트/집 안 물건/과일/교통수단) × 3단계 크기(작음/중간/큼)로 구성됩니다.

- **1~18턴**: 테마를 3턴 단위로 순서대로 진행 (예: 1턴 우주-작음 → 2턴 우주-중간 → 3턴 우주-큼 → 4턴 바다-작음 → … → 18턴 교통수단-큼)
- **19턴 이후**: 매 턴 테마와 크기를 무작위로 선정
- 크기에 따라 **충돌판정(히트박스)도 함께 커지고 작아집니다** (작음 15px / 중간 22px / 큼 32px 반지름) — 큰 장애물은 눈에 잘 띄지만 피하기 물리적으로 어렵고, 작은 장애물은 반대로 스치기 쉬운 대신 히트박스가 작습니다.
- 기존의 "턴이 지날수록 스폰 빈도·스크롤 속도가 상승하는" 난이도 곡선은 이 테마 로테이션과 별개로 그대로 유지됩니다.

## 스펙 상 "제안 바람"으로 명시된 부분에 대한 설계 결정

원 기획서에서 수치·규칙이 명시되지 않고 "상식 선에서 제안"을 요청한 항목들은 아래와 같이 구현했습니다.

- **스폰/난이도 곡선**: 코인 0.45~0.9초, 돈 1.4~2.4초, 장애물 0.7~1.7초 간격으로 랜덤 스폰. 완료한 비행 턴 수(`turnsCompleted`, 최대 15레벨)에 비례해 스폰이 빨라지고 스크롤 속도(200→410px/s)도 증가.
- **몬스터 체력/전투**: 체력 30 + 턴수×4 (최대 90). 플레이어 기본 공격력 10, 쿨다운 0.45초. 몬스터는 1.6~2.4초 간격으로 공격을 예고(⚠️ 연출) 후 명중.
- **보석 20종류 수집**: 기획서 6-3에서 "종류 상관없이 20개 모으면 됨"으로 단순화되어 있어, 보석을 하나의 재화 풀로 취급하고 20개마다 트로피 1개로 자동 전환됩니다.
- **트로피 10개 → 날개 교환**: 보유하지 않은 날개 중 랜덤 지급. 모든 날개를 이미 보유한 경우 코인 20개로 대체 보상.
- **게임 오버 리셋 범위**: "처음(방)으로 리셋"을 코인만 초기화 + 목숨 3으로 회복으로 해석했습니다. 보석/돈/트로피/보유 날개 등 메타 진행도는 유지됩니다(완전 초기화 시 진행이 지나치게 가혹하다고 판단).
- **냉장고 음료 보충**: 기획서에 보충 방법이 없어, 비행 턴을 1회 완료할 때마다 음료 +1(최대 5개)로 보충되도록 임의 설계했습니다.
- **전투 중 "죽음" 처리**: 몬스터 공격 명중 시 목숨 -1, 보석 -1 후 즉시 부활(무적 1.2초)하며 몬스터 체력은 유지된 채 전투가 계속됩니다. 목숨이 0이 되면 게임 오버.
- **날개별 전투 보정치**: 무지개(공격력 +30%, 전투당 1회 공격 무효화 방패), 불꽃(+20%), 물(+15%, 공속 +10%), 전기(공속 +30%, 10회 사용마다 10초간 파워 50% 감소) — 기획서의 "칼 장착" 설명을 실제 수치 차별화로 구체화했습니다.
- **구름 날개 은신**: 비행 중 주기적으로 구름 장식이 등장하며, 그 안에 들어가면 몬스터와 충돌해도 전투가 발생하지 않습니다.
- **하늘 날개 날씨**: 해/비/구름 3종 전환, 배경 색감·빗줄기 연출만 변경되는 순수 연출용(명시된 대로 게임플레이에는 영향 없음).
- **저장**: `localStorage`에 진행 상황을 자동 저장합니다. 최초 1회 음료 팝업→날개 선택 흐름은 이후 재접속 시 다시 나타나지 않습니다. 방 화면 우측 상단 "새로 시작하기" 버튼으로 저장 데이터를 초기화할 수 있습니다.
- **마사지 의자**: "10초 동안 비행 중 획득하는 돈(💰)이 보석(💎)으로 대신 지급"으로 변경했습니다.
- **우편 편지 랜덤 선정**: 5종 중 동일 확률로 무작위 선택합니다.

## 파일 구성

- `index.html` — 화면 구조 (방/상점/비행/모달)
- `style.css` — 전체 스타일
- `game.js` — 게임 로직 전체 (상태 관리, 비행/전투 루프, 렌더링)
